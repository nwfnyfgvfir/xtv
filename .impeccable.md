# Frontend design context

The current direction is approved by the user: a restrained, media-first library with graphite surfaces and a mineral-green accent. It replaces the former warm gold cinema theme.

- Keep Vue 3, the existing routes, API contracts, authentication, player integration, list restoration, and all media operations.
- Desktop: a quiet fixed sidebar and a compact top search bar. Mobile: a compact header and five-item bottom navigation.
- Posters carry the visual interest. The user chose landscape poster frames because their original covers are landscape. Use one shared 3:2 ratio for gallery and detail artwork, loading skeletons, missing-image placeholders, and duplicate thumbnails. Prefer the complete cover before the thumbnail, and retain image recovery candidates. Use object-fit: fill to show the complete image across the entire frame. Never crop poster content or introduce blurred filler backgrounds. The detail preview preserves the original image proportions. Never let source image proportions or loading state change card geometry. Keep readable filenames, restrained badges, and ample spacing between rows.
- Dark backgrounds: #101416 / #161b1e / #1a2023. Accent: #73d5b0. Light mode maps the same semantic tokens to pale mineral surfaces and #247955.
- Prefer local Chinese sans-serif fonts and a local geometric display stack. Do not add external font or image dependencies.
- Media details prioritize play, favorite, synopsis, and cast. Put rename, delete, translation, and rescraping in a secondary management area, preserving every operation.
- Settings use clearly separated media-library, metadata, translation, image, and system sections. Keep form state when changing sections and preserve existing secret-handling rules.
- Image delivery has two modes: the site proxy or one shared remote URL template. MetaTube uses the same template field and renderer as any external proxy, not a separate mode. Keep original remote URLs. All sources use one permanent image store with automatic background backups; the site proxy reuses those copies while remote templates fall back to them after a load failure. Apply one delivery policy to posters, portraits, favorites and duplicates. Remove the separate disk cache and its settings; do not migrate old cache files or convert the retired MetaTube mode. Show backup progress in image settings. Inline-only Stash artwork uses the same local store.
- Publish inline artwork, local fallbacks and the site proxy through the configured site image base URL when set. Keep stored image paths relative, preserve remote proxy choices, and leave the UI/API/video origin unchanged. Changing or clearing the image host must not require migration or rescraping.
- Maintain 44px touch targets, keyboard focus, useful labels, reduced-motion support, and a usable light theme.
- No decorative gold outlines, large ambient gradients, excessive shadows, or fabricated metadata/status information.
